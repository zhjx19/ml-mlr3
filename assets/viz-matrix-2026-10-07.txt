## 4. 两条本轮新暴露的限制（文档已据此改写）

### 4.1 调优图有两类返回对象，落盘方式不同

performance / incumbent / parallel / points → ggplot2::ggplot   ggsave OK
marginal（无论是否给 cols_x）      → DelayedPatchworkPlot  ggsave ERR
parameter                          → DelayedPatchworkPlot  ggsave ERR
pairs                              → ggmatrix/GGally::ggmatrix  ggsave OK

  A ggsave(plot = parameter 图)，未 attach patchwork
    → ERR: no applicable method for 'grid.draw' applied to an object of class "DelayedPatchworkPlot"
  C ggsave(plot = parameter 图)，已 library(patchwork)
    → ERR: 同上（patchwork 1.3.2 只为该类注册了 print 方法，methods(class="DelayedPatchworkPlot") = "print"）
  B print(parameter 图) + png() 设备
    → OK
→ 落盘修法：png("f.png", ...); print(autoplot(instance, type = "parameter")); dev.off()

### 4.2 tuning type="surface" 只接受两个连续超参

[PASS] surface：regr.ranger(mtry.ratio, sample.fraction)  两纯连续       2.94s
[PASS] surface：classif.glmnet(alpha, s)                   两纯连续       1.47s
[FAIL] surface：classif.rpart(cp, minsplit)                含整数超参
  → Incompatible types during auto-converting column 'minsplit':
     failed to convert from class 'numeric' to class 'integer'   [Class: Mlr3ErrorInput]
[FAIL] surface：classif.rpart(cp, maxdepth)                含整数超参       同上（maxdepth）
[FAIL] surface：minsplit = to_tune(p_int(1, 20))           p_int 显式声明也拦不住
（对照：同一实例的 performance/incumbent/parameter/parallel/points/pairs/marginal 七类图全部 PASS，
  即整数超参只影响 surface 这一类。）
